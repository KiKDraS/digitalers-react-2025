Clase de React: Peticiones AJAX 🚀

Cómo hablar con servidores usando GET, POST, PUT y DELETE.

¿Qué es AJAX y una API? (La Analogía del Restaurante 🍽️)

Imagina que tu aplicación de React es un cliente en un restaurante.

  • La Cocina es el Servidor (o Base de Datos), donde está toda la comida (los datos).
  • El Menú es la Documentación de la API, te dice qué puedes pedir.
  • El Mesero es la API (AJAX / Fetch). Es el intermediario que toma tus pedidos y te trae la comida.

AJAX es simplemente el término para describir esta acción de pedir datos al servidor "por lo bajo", sin tener que recargar toda la página.

Los 4 Verbos Principales (CRUD)

Tus "pedidos" al mesero (la API) usan diferentes "verbos" según lo que quieras hacer. Esto se conoce como CRUD (Create, Read, Update, Delete).

📖 GET (Read - Leer)

Propósito: Pedir y recibir datos del servidor. (Ej: Cargar la lista de productos).

✍️ POST (Create - Crear)

Propósito: Enviar datos nuevos al servidor para que los cree. (Ej: Enviar un formulario de registro).

🔄 PUT (Update - Actualizar)

Propósito: Enviar datos para modificar algo que ya existe. (Ej: Editar tu foto de perfil).

🗑️ DELETE (Delete - Borrar)

Propósito: Pedirle al servidor que elimine un dato específico. (Ej: Borrar un tweet).

Herramientas de React para AJAX

Para hacer estas peticiones, usamos tres herramientas principales:

  1. Fetch API: Es la función moderna que trae el navegador para hacer las peticiones (llamar al mesero).
  2. Hook `useState`: Para guardar los datos que recibimos del servidor (ej. `const [posts, setPosts] = useState([])`).
  3. Hook `useEffect`: Para ejecutar la petición `fetch` justo cuando el componente se carga por primera vez.

Nuestro Servidor de Pruebas: MockAPI.io 🧪

Para esta clase, usaremos un servicio gratuito llamado MockAPI. ¿Por qué?

APIs como JSONPlaceholder son geniales para practicar `GET`, pero tienen un truco: **son de solo lectura**. Si haces un `POST` o `DELETE`, la API te dirá "OK, lo hice", pero en realidad no guarda ni borra nada.

¡MockAPI sí guarda tus cambios!
Cuando haces un POST, los datos se crean. Cuando haces un DELETE, se borran. Esto nos permite ver en tiempo real cómo nuestra aplicación de React manipula datos "reales" en un servidor.

Pasos para configurar tu MockAPI:

  1. Ve a mockapi.io y regístrate (puedes usar tu cuenta de GitHub).
  2. Crea un nuevo "Proyecto".
  3. Dentro del proyecto, crea un nuevo "Recurso" (Resource). Llámalo posts (en minúsculas).
  4. Al crear el recurso, te pedirá definir la "Forma" (Schema). Podemos usar title (un string) y body (un string).
  5. ¡Listo! MockAPI te dará una URL única. Se verá algo así:
    https://[TU_ID_UNICO].mockapi.io/posts

Esa es la URL que usaremos como nuestra API_URL en el código.

Ejemplo Práctico: Un Blog (Conectado a MockAPI)

Crearemos un componente que maneja nuestra lista de posts de MockAPI.

Usaremos async / await. Es la forma moderna de manejar peticiones y hace el código más fácil de leer. Siempre lo usaremos dentro de un bloque try...catch para manejar errores. 

import React, { useState, useEffect } from 'react';
import { Spinner } from './Spinner'; // Un componente de carga

// 👇 ¡IMPORTANTE! Reemplaza esto con tu propia URL de MockAPI
const API_URL = 'https://[TU_ID_UNICO].mockapi.io/posts';

function PostManager() {
  const [posts, setPosts] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
  
  const [newPostTitle, setNewPostTitle] = useState('');

  // ------------------------------------
  // 📖 GET (Leer) - Se ejecuta al cargar el componente
  // ------------------------------------
  useEffect(() => {
    const fetchPosts = async () => {
      try {
        setLoading(true);
        // No necesitamos límite, MockAPI no trae tantos datos
        const response = await fetch(API_URL); 
        if (!response.ok) throw new Error('Error al cargar los posts');
        setPosts(await response.json());
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };
    fetchPosts();
  }, []); // El array vacío [] significa: "ejecútate solo una vez al inicio"

  // ------------------------------------
  // ✍️ POST (Crear) - Se ejecuta con el formulario
  // ------------------------------------
  const handleCreatePost = async (e) => {
    e.preventDefault();
    setLoading(true);
    try {
      const newPost = {
        title: newPostTitle,
        body: 'Este es el cuerpo del post.',
        // MockAPI autogenera el 'id' y 'createdAt'
      };

      const response = await fetch(API_URL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(newPost), 
      });

      if (!response.ok) throw new Error('No se pudo crear el post');
      
      const createdPost = await response.json();
      // Actualizamos el estado local para ver el cambio al instante
      // Ponemos el nuevo post al final de la lista
      setPosts([...posts, createdPost]);
      setNewPostTitle('');
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

  // ------------------------------------
  // 🔄 PUT (Actualizar) - Se ejecuta al hacer clic en un post
  // ------------------------------------
  const handleUpdatePost = async (id) => {
    setLoading(true);
    try {
      const updatedPostData = {
        title: `(Actualizado) ${posts.find(p => p.id === id).title}`,
      };
      
      // Apuntamos a la URL específica del post: .../posts/1
      const response = await fetch(`${API_URL}/${id}`, {
        method: 'PUT',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(updatedPostData),
      });

      if (!response.ok) throw new Error('No se pudo actualizar');
      
      const updatedPost = await response.json();
      // Actualizamos el estado local
      setPosts(posts.map(p => (p.id === id ? updatedPost : p)));
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

  // ------------------------------------
  // 🗑️ DELETE (Borrar) - Se ejecuta al hacer clic en "Eliminar"
  // ------------------------------------
  const handleDeletePost = async (id) => {
    setLoading(true);
    try {
      // Apuntamos a la URL específica del post: .../posts/1
      const response = await fetch(`${API_URL}/${id}`, {
        method: 'DELETE',
      });

      if (!response.ok) throw new Error('No se pudo eliminar');
      
      // Actualizamos el estado local, filtrando el post eliminado
      setPosts(posts.filter(p => p.id !== id));
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

  // --- Renderizado del componente ---
  
  if (error) return <div className="alert alert-danger">Error: {error}</div>;

  return (
    <div>
      <h3>Crear Nuevo Post</h3>
      <form onSubmit={handleCreatePost} className="mb-4">
        <div className="input-group">
          <input
            type="text"
            className="form-control"
            value={newPostTitle}
            onChange={(e) => setNewPostTitle(e.target.value)}
            placeholder="Título del nuevo post"
            required
          />
          <button type="submit" className="btn btn-primary">Crear (POST)</button>
        </div>
      </form>

      <h3>Lista de Posts (GET)</h3>
      {loading && <Spinner />}
      
      <ul className="list-group">
        {posts.map(post => (
          <li key={post.id} className="list-group-item d-flex justify-content-between align-items-center">
            {post.id} - {post.title}
            <div>
              <button onClick={() => handleUpdatePost(post.id)} className="btn btn-warning btn-sm me-2">
                Actualizar (PUT)
              </button>
              <button onClick={() => handleDeletePost(post.id)} className="btn btn-danger btn-sm">
                Eliminar (DELETE)
              </button>
            </div>
          </li>
        ))}
      </ul>
    </div>
  );
}
