React: Custom Hooks, Composición y AJAX 🚀

Custom Hooks: Creando Lógica Reutilizable

Un custom hook es una función que nos permite extraer y reutilizar lógica con estado de un componente. En lugar de copiar y pegar, centralizas la lógica en un hook reutilizable.

Ejemplo: useLocalStorage

Crearemos un hook que sincroniza un estado de React con el localStorage del navegador.


import { useState, useEffect } from 'react';

function useLocalStorage(key, initialValue) {
  const [storedValue, setStoredValue] = useState(() => {
    try {
      const item = window.localStorage.getItem(key);
      return item ? JSON.parse(item) : initialValue;
    } catch (error) {
      return initialValue;
    }
  });

  useEffect(() => {
    window.localStorage.setItem(key, JSON.stringify(storedValue));
  }, [key, storedValue]);

  return [storedValue, setStoredValue];
}

Composición: Construyendo UIs como Legos 🧩

La composición consiste en construir interfaces combinando componentes más pequeños y reutilizables.

Ejemplo: Creando una Tarjeta de Alerta

Crearemos un componente genérico <Card /> y lo usaremos para componer una <AlertCard />. 


// 1. El componente genérico reutilizable con clases de Bootstrap
function Card({ children }) {
  return <div className="card shadow-sm">{children}</div>;
}

// 2. El componente específico que USA la composición
function AlertCard() {
  return (
    <Card>
      <div className="card-body">
        <h3 className="card-title text-danger">⚠️ ¡Acción Requerida!</h3>
        <p className="card-text">Debes actualizar tu información de perfil.</p>
      </div>
    </Card>
  );
}

Formularios con Composición 📝

Para lograr la máxima reutilización, podemos crear componentes genéricos para cada parte del formulario: un contenedor, los campos de entrada y un hook para la lógica.

Ejemplo: Formulario Componible

Este ejemplo combina un componente <Form /> para la estructura, un <Input /> para los campos, y el hook useForm para el estado.


import React, { useState } from 'react';

// 1. Hook para manejar la lógica del formulario
const useForm = (initialState = {}) => {
  const [formData, setFormData] = useState(initialState);
  const handleChange = (e) => {
    const { name, value } = e.target;
    setFormData(prev => ({ ...prev, [name]: value }));
  };
  return { formData, handleChange };
};

// 2. Componente de Input reutilizable
const Input = ({ label, name, ...rest }) => (
  <div className="mb-3">
    <label htmlFor={name} className="form-label">{label}</label>
    <input id={name} name={name} className="form-control" {...rest} />
  </div>
);

// 3. Componente Form reutilizable que provee un contenedor estilizado
const Form = ({ title, onSubmit, children }) => (
  <div className="card shadow-sm">
    <div className="card-body p-4">
      <h2 className="card-title text-center mb-4">{title}</h2>
      <form onSubmit={onSubmit}>
        {children}
      </form>
    </div>
  </div>
);

// 4. Componente final que compone todo
function LoginForm() {
  const { formData, handleChange } = useForm({ email: '', password: '' });

  const handleSubmit = (e) => {
    e.preventDefault();
    alert(`Iniciando sesión con: ${formData.email}`);
  };

  return (
    <Form title="Iniciar Sesión" onSubmit={handleSubmit}>
      <Input
        label="Correo Electrónico"
        type="email"
        name="email"
        value={formData.email}
        onChange={handleChange}
      />
      <Input
        label="Contraseña"
        type="password"
        name="password"
        value={formData.password}
        onChange={handleChange}
      />
      <button type="submit" className="btn btn-primary w-100 mt-3">
        Ingresar
      </button>
    </Form>
  );
}

Peticiones AJAX y Manejo de Estados Asíncronos 🌐

La forma de manejar los estados de carga y error al obtener datos ha evolucionado con el tiempo.

Enfoque 1 (Clásico): `useEffect` + `useState`


import React, { useState, useEffect } from 'react';

const Spinner = () => (
  <div className="d-flex justify-content-center p-4">
    <div className="spinner-border" role="status">
      <span className="visually-hidden">Loading...</span>
    </div>
  </div>
);

function UserProfileClassic({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchUser = async () => {
      try {
        const response = await fetch(`https://jsonplaceholder.typicode.com/users/${userId}`);
        if (!response.ok) throw new Error('No se pudo obtener el usuario.');
        setUser(await response.json());
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };
    fetchUser();
  }, [userId]);

  if (loading) return <Spinner />;
  if (error) return <div className="alert alert-danger">Error: {error}</div>;

  return (
    <div className="card shadow-sm">
      <div className="card-body">
        <h2 className="card-title">{user?.name}</h2>
        <p className="card-text">Email: {user?.email}</p>
      </div>
    </div>
  );
}

Enfoque 2 (React 18 y menor): `Suspense` para Code-Splitting

Antes de React 19, <Suspense> se usaba principalmente para el code-splitting: mostrar un estado de carga mientras se descarga el código de un componente usando React.lazy().

1. Crear un Error Boundary Reutilizable

Modificamos el ErrorBoundary para que acepte una UI de fallback como prop, haciéndolo más flexible. 


import React from 'react';

class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false };
  }
  static getDerivedStateFromError(error) {
    // Actualiza el estado para que el siguiente renderizado muestre la UI de fallback.
    return { hasError: true };
  }
  componentDidCatch(error, errorInfo) {
    // También puedes registrar el error en un servicio de reporte.
    console.error("Error atrapado por ErrorBoundary:", error, errorInfo);
  }
  render() {
    if (this.state.hasError) {
      // Renderiza la UI de fallback que recibimos por props.
      return this.props.fallback;
    }
    return this.props.children;
  }
}
export default ErrorBoundary;

¿Por qué un Componente de Clase?

Actualmente, los Error Boundaries solo pueden ser componentes de clase. Esto se debe a que la funcionalidad de "atrapar" errores de los componentes hijos se implementa a través de métodos de ciclo de vida específicos: static getDerivedStateFromError() y componentDidCatch().

Los Hooks en los componentes funcionales, como useEffect, se ejecutan después de que el renderizado se ha completado (commit), por lo que no pueden interceptar errores que ocurren durante el renderizado de la misma manera. Por esta razón, no existe un Hook nativo que reemplace esta funcionalidad.

2. Usar `React.lazy` con el Error Boundary Reutilizable


import React, { Suspense, lazy } from 'react';
import ErrorBoundary from './ErrorBoundary';
// const Spinner = () => ( ... );

const UserProfileDetails = lazy(() => import('./UserProfileDetails'));

function UserProfileLazy() {
  const errorFallback = (
    <div className="alert alert-danger">
      No se pudo cargar el componente de perfil.
    </div>
  );

  return (
    <div className="card">
      <div className="card-header">
        <h3>Perfil de Usuario (Lazy Loaded)</h3>
      </div>
      <div className="card-body">
        <ErrorBoundary fallback={errorFallback}>
          <Suspense fallback={<Spinner />}>
            <UserProfileDetails userId={1} />
          </Suspense>
        </ErrorBoundary>
      </div>
    </div>
  );
}

Enfoque 3 (React 19): `Suspense` + `use()` para Data Fetching

React 19 integra el fetching de datos directamente con Suspense a través del hook use().


import React, { Suspense, use } from 'react';
import ErrorBoundary from './ErrorBoundary';
// const Spinner = () => ( ... );

function fetchUser(userId) {
  return fetch(`https://jsonplaceholder.typicode.com/users/${userId}`)
    .then(res => {
      if (!res.ok) throw new Error(`El usuario ${userId} no existe.`);
      return res.json();
    });
}

function UserProfile({ userId }) {
  const user = use(fetchUser(userId));
  return (
    <div className="card-body">
      <h2 className="card-title">{user.name}</h2>
      <p className="card-text">Email: {user.email}</p>
    </div>
  );
}

function UserPageR19({ userId }) {
  const errorFallback = (
    <div className="alert alert-danger m-3">
      Hubo un problema al cargar el perfil del usuario.
    </div>
  );

  return (
    <div className="card shadow-sm">
      <div className="card-header">
        <h3>Perfil de Usuario</h3>
      </div>
      <ErrorBoundary fallback={errorFallback}>
        <Suspense fallback={<Spinner />}>
          <UserProfile userId={userId} />
        </Suspense>
      </ErrorBoundary>
    </div>
  );
}
