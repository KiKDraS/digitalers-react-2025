Ciclo de Vida, Hooks, Custom Hooks y Formularios

El Ciclo de Vida del Componente

Imagina que cada componente de React es como un ser vivo. Pasa por tres fases principales a lo largo de su existencia en tu aplicación:

  1. Nacimiento (Montaje - Mounting): Es cuando el componente se crea y se inserta por primera vez en el DOM (la estructura de tu página web).
  2. Vida (Actualización - Updating): Durante su vida, el componente se vuelve a renderizar cuando sus props o su state se modifican.
  3. Muerte (Desmontaje - Unmounting): Cuando un componente ya no es necesario, se elimina del DOM.

Entender este ciclo es clave para ejecutar código en momentos específicos.

El Ciclo de Vida con Hooks: El Poder de useEffect

En React moderno, manejamos todas las fases del ciclo de vida con un hook principal: useEffect. Nos permite ejecutar "efectos secundarios" (código que interactúa fuera de React) en el momento preciso.

Casos de Uso Fundamentales:

  • Ejecutar solo en el Montaje: useEffect(() => { ... }, [])
  • Ejecutar cuando algo cambia: useEffect(() => { ... }, [valor1, valor2])
  • Limpiar al Desmontar: useEffect(() => { return () => { ... } }, [])

Ejemplo Práctico: Un Contador Funcional


import React, { useState, useEffect } from 'react';

function ContadorFuncional() {
  const [contador, setContador] = useState(0);

  // 1. MONTAJE y DESMONTAJE
  useEffect(() => {
    console.log('EFECTO DE MONTAJE: El componente apareció.');
    document.title = `Contador: 0`;

    return () => { // Función de limpieza
      console.log('EFECTO DE LIMPIEZA: El componente va a desaparecer.');
      document.title = 'React App';
    };
  }, []); // <-- Array vacío = solo al montar y desmontar.

  // 2. ACTUALIZACIÓN
  useEffect(() => {
    if (contador > 0) {
      console.log(`EFECTO DE ACTUALIZACIÓN: Contador es ${contador}.`);
    }
    document.title = `Contador: ${contador}`;
  }, [contador]); // <-- Depende de 'contador'.

  console.log('RENDER: Dibujando el componente...');
  return (
    <div>
      <h2>Contador con Hooks</h2>
      <p>Has hecho clic {contador} veces.</p>
      <button onClick={() => setContador(c => c + 1)}>Incrementar</button>
    </div>
  );
}

🏋️‍♂️ Ejercicio Práctico con useEffect

Objetivo: Crear un componente que cambie el color de fondo de un div cada vez que el usuario escriba en un input.

Ver Ejercicio y Solución

Código de Inicio:


import React, { useState, useEffect } from 'react';

function CambiadorDeColor() {
  const [color, setColor] = useState('lightblue');
  // TU CÓDIGO CON useEffect VA AQUÍ
  return (
    <div>
      <h3>Ejercicio: Cambiador de Color</h3>
      <input
        type="text"
        placeholder="Escribe un color (ej: red, #FF5733)"
        onChange={(e) => setColor(e.target.value)}
      />
      <div id="caja-color" style={{ width: '100px', height: '100px',
        marginTop: '10px', border: '1px solid black', backgroundColor: 'lightblue' }}
      ></div>
    </div>
  );
}

Solución Propuesta:


// ... dentro del componente CambiadorDeColor
useEffect(() => {
  const caja = document.getElementById('caja-color');
  if (caja) {
    caja.style.backgroundColor = color;
  }
  console.log(`El color del div cambió a: ${color}`);
}, [color]); // El efecto se ejecuta cada vez que 'color' cambia.

Creando Custom Hooks (Hooks Personalizados)

¿Qué son y por qué los necesitamos?

Un custom hook es una función que nos permite extraer y reutilizar lógica con estado de un componente. En lugar de copiar y pegar, centralizas la lógica en un hook reutilizable.

Reglas de Oro:

  1. Su nombre siempre debe empezar con la palabra use (ej: useWindowSize).
  2. Solo pueden ser llamados dentro de componentes funcionales o de otros custom hooks.

Ejemplo: Creando useDocumentTitle

1. Crear el archivo del Hook (useDocumentTitle.js)


import { useEffect } from 'react';

function useDocumentTitle(title) {
  useEffect(() => {
    document.title = title;
    return () => { document.title = 'React App'; };
  }, [title]);
}
export default useDocumentTitle;

2. Usar nuestro Custom Hook


import React, { useState } from 'react';
import useDocumentTitle from './useDocumentTitle';

function ComponenteConTituloSimple() {
  const [nombre, setNombre] = useState('');
  useDocumentTitle(nombre ? `Hola, ${nombre}` : 'Escribe tu nombre');

  return (
    <div>
      <h3>Ejemplo de Custom Hook: `useDocumentTitle`</h3>
      <input
        type="text"
        placeholder="Escribe tu nombre"
        value={nombre}
        onChange={(e) => setNombre(e.target.value)}
      />
      <p>Mira el título de la pestaña del navegador.</p>
    </div>
  );
}

Formularios en React: El Enfoque de Composición

En React, en lugar de crear formularios monolíticos, a menudo usamos la composición. Esto significa construir UIs complejas a partir de piezas más pequeñas y reutilizables. Crearemos un formulario de login usando un componente genérico <Input /> y un contenedor <Form />.

Componentes Controlados: La idea principal es que el estado de React (usando useState) es la "única fuente de verdad". El valor del input está controlado por el estado del componente, y se actualiza solo a través de onChange.

1. Creando los Componentes Reutilizables

Primero, definimos un <Input /> y un <Form /> genéricos que no saben nada sobre un "login". Son solo piezas de construcción.


// Componente reutilizable para cualquier campo de texto
const Input = ({ label, type, name, value, onChange }) => (
  <label style={{ display: 'flex', flexDirection: 'column', gap: '5px' }}>
    {label}
    <input type={type} name={name} value={value} onChange={onChange} required />
  </label>
);

// Componente reutilizable que actúa como contenedor del formulario
const Form = ({ title, onSubmit, children }) => (
  <form
    onSubmit={onSubmit}
    style={{ display: 'flex', flexDirection: 'column', gap: '15px',
      border: '1px solid #ccc', padding: '20px', borderRadius: '8px' }}
  >
    <h3 style={{ marginTop: 0, textAlign: 'center' }}>{title}</h3>
    {children}
  </form>
);

2. Componiendo el Formulario de Login

Ahora, usamos nuestros componentes genéricos para construir el <LoginForm />. Aquí es donde vive toda la lógica específica del login, como el manejo del estado y la función de envío.


import React, { useState } from 'react';

// (Aquí irían las definiciones de los componentes Input y Form de arriba)

function LoginForm() {
  // El estado vive en el componente específico, no en los reutilizables.
  const [formData, setFormData] = useState({
    email: '',
    password: ''
  });

  const handleChange = (e) => {
    const { name, value } = e.target;
    setFormData(prevData => ({
      ...prevData,
      [name]: value
    }));
  };

  const handleSubmit = (e) => {
    e.preventDefault(); // Evita que la página se recargue
    alert(`Iniciando sesión con: ${formData.email}`);
    console.log('Datos enviados:', formData);
  };

  return (
    // Usamos el componente Form como contenedor
    <Form title="Inicio de Sesión" onSubmit={handleSubmit}>
      {/* Componemos el formulario con nuestros inputs reutilizables */}
      <Input
        label="Correo Electrónico"
        type="email"
        name="email"
        value={formData.email}
        onChange={handleChange}
      />
      <Input
        label="Contraseña"
        type="password"
        name="password"
        value={formData.password}
        onChange={handleChange}
      />
      <button type="submit">Iniciar Sesión</button>
    </Form>
  );
}

export default LoginForm;

Ventajas de este enfoque:

  • Reutilización: Puedes usar <Input /> y <Form /> en cualquier otro formulario de tu aplicación (registro, contacto, etc.).
  • Claridad: El componente <LoginForm /> es muy legible. Describe qué contiene, pero no se preocupa por los detalles de cómo se renderiza cada input.
  • Mantenimiento Sencillo: Si quieres cambiar el estilo de todos los inputs de tu aplicación, solo modificas el componente <Input /> en un solo lugar.
